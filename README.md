  # 🐍🌊 Анти ИИ: Змея и Океан

**3D-игра с открытым исходным кодом в философии Anti-AI Shield**

Погрузитесь в захватывающую трёхмерную игру, где вы управляете элегантной стеклянной змеёй на живописном дне океана. Ваша задача — найти единственный правильный туннель среди ложных путей и каменных ловушек, чтобы выбраться на свободу, и всё это всего за 3 минуты!

## 🌟 Особенности игры
- 🌊 **Потрясающая 3D-графика**: Реалистичные водные лучи, плавающие рыбки, пузырьки и стеклянный дизайн (glassmorphism) интерфейса на базе Three.js.
- 📱 **Полная мобильная адаптация**: Удобное сенсорное управление с красными стеклянными кнопками, оптимизированное для любых экранов.
- 🔒 **Приватность и безопасность**: Игра работает полностью офлайн (PWA-ready), не собирает персональные данные, не использует трекеры и является частью социального проекта "Anti-AI Shield".
- 🏆 **Доска почёта**: Безопасная интеграция с таблицей лидеров через защищённые криптографические токены.
- 🔊 **Иммерсивный звук**: Пространственные звуковые эффекты и голосовые подсказки через Web Speech API.

## 🎮 Как играть
1. Ваша цель — найти **правильный туннель** (он светится изнутри), ведущий на свободу.
2. Избегайте столкновений с каменными глыбами и ложными туннелями.
3. У вас есть **3 минуты** и право ошибиться не более **5 раз** (осмотреть 5 ложных туннелей).
4. Используйте подсказки температуры и звука, чтобы определить близость к цели.

## 🕹️ Управление
- **На компьютере**: 
  - `←` / `A` или `→` / `D` — поворот змеи.
  - `↑` / `W` — ускорение.
  - `↓` / `S` — замедление.
- **На смартфоне**: Используйте экранные сенсорные кнопки с красной стеклянной подсветкой.

## 🛠️ Технологии
- **Ядро**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **3D-графика**: Three.js (r128 / r157)
- **Аудио**: Web Audio API, Web Speech API
- **Стили**: Glassmorphism, CSS Animations, Adaptive Design
